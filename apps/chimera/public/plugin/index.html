CHIMERA Open the voice

The plugin

CHIMERA in your DAW: notes sing lyrics, say lines or play mouth drums in time with the host. The same voice and screens as this website, saved with your project.

Mac: CLAP, VST3 and AU. macOS 11 or later, Apple silicon and Intel. Signed and notarised. Tried in REAPER, Bitwig and FL Studio.

Linux: CLAP and VST3, x86_64, glibc 2.35 or later (Ubuntu 22.04, Debian 12, Fedora 36 and newer). The plugin's editor opens in your web browser. Tried in REAPER.

Download for Mac Download for Linux

A Windows build isn't released yet.

Install from a terminal

curl -fsSL https://chimera.audio/install.sh | sh

On a Mac or Linux, it downloads the latest release, checks it, and copies the plugins into your own plugin folders. No password needed. Run it again to update.

Only some formats: | sh -s -- --formats clap,vst3. Remove: | sh -s -- --uninstall.

Install by hand

Unpack the download and copy each plugin into its folder. On a Mac, Finder's Go > Go to Folder opens a path.

Mac
CHIMERA.clap~/Library/Audio/Plug-Ins/CLAP
CHIMERA.vst3~/Library/Audio/Plug-Ins/VST3
CHIMERA.component~/Library/Audio/Plug-Ins/Components
Linux
CHIMERA.clap~/.clap
CHIMERA.vst3~/.vst3

Then rescan plugins in your DAW and put CHIMERA on an instrument track.
